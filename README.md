# 💼 HR Recruitment Tracker

A web-based HR Recruitment Tracker developed to manage candidate information, track interviews, and monitor the recruitment process in one place.

## 🌐 Live Demo

👉 [View HR Recruitment Tracker](https://kirthika-data.github.io/HR-Recruitment-Tracker/)

## 📌 About the Project

This project is a simple HR recruitment management application that helps track candidates from application to final selection.

It provides a dashboard to view recruitment information and analytics in an easy-to-understand format.

## ✨ Features

- 👥 Add and manage candidate details
- 🔍 Search and filter candidates
- 📅 Schedule and track interviews
- 📊 View recruitment KPIs
- 📈 Analyze candidate status and positions
- 📝 Track recruitment progress
- 💾 Store data using browser Local Storage
- 📱 Responsive design for desktop and mobile

## 📊 Dashboard

The dashboard displays important recruitment metrics such as:

- Total Candidates
- Interviews
- Selected Candidates
- Rejected Candidates
- Selection Rate
- Recent Candidates

## 📈 Analytics

The Analytics page provides visual insights into:

- Candidate Status
- Candidates by Position
- Recruitment Performance

Interactive charts are created using **Chart.js**.

## 🔄 Recruitment Process

**Candidate Added → Shortlisted → Interview → Selected / Rejected**
